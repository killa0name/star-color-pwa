# Star Color

A child-friendly, installable iPad PWA coloring book optimized for Apple Pencil.

## Included
- 10 original winter-magic black-and-white coloring pages
- Large child-friendly gallery and controls
- Apple Pencil pressure support via Pointer Events
- Coalesced pointer events for smoother ink
- Apple Pencil-only palm-guard mode (on by default)
- Finger drawing toggle
- Brush, pencil, crayon, eraser
- Three simple brush sizes
- Undo and protected double-tap Clear
- Automatic local saving using IndexedDB
- Save/share finished coloring as PNG
- Offline caching after first load
- Search-engine exclusion via robots meta, robots.txt, and X-Robots-Tag headers

On iPad: open the HTTPS URL in Safari, Share > Add to Home Screen.

Vercel deployment source: GitHub `main`.
